# Support

Thanks for playing *1977 — Aircraft Warfare*. Here's where to get help.

## Before you ask

- Read the [README](README.md) — install, run, controls
- Check [CONTROLS.md](CONTROLS.md) for full input reference
- Skim open and closed [issues](https://github.com/khaaliswooden-max/1977/issues) to see if your question has been answered

## Getting help

| I want to…                             | Go to…                                                                      |
| -------------------------------------- | --------------------------------------------------------------------------- |
| Report a bug                           | [Open an issue](https://github.com/khaaliswooden-max/1977/issues/new/choose) (Bug Report template) |
| Request a feature                      | Open an issue (Feature Request template)                                    |
| Ask "how do I…" about gameplay         | GitHub Discussions (if enabled) or an issue labelled `question`             |
| Report a security problem              | [SECURITY.md](SECURITY.md) — **do not** post publicly                       |
| Contribute code, art, or audio         | [CONTRIBUTING.md](CONTRIBUTING.md)                                          |
| Report conduct problems                | Contact point below (kept private)                                          |

## Maintainer contact

For conduct issues, security reports, or anything else that shouldn't be public, reach the maintainer at:

- GitHub: [@khaaliswooden-max](https://github.com/khaaliswooden-max)
- Email: *add a contact email here before release*

## Response times

This is a hobby project. Expect:

- Issues: response within **~1 week**
- Pull requests: initial review within **~2 weeks**
- Security reports: acknowledgement within **72 hours** (see [SECURITY.md](SECURITY.md))

No response within those windows? Feel free to bump the thread once.

## What we can't help with

- Modifying or distributing commercial ROMs or copyrighted arcade assets
- Bypassing anti-cheat or DRM on other games
- General "help me debug my project" questions unrelated to 1977
